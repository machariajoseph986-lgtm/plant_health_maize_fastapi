# Corn Leaf Disease Classification

A TensorFlow image-classification project that identifies four corn leaf conditions:

- Blight
- Common Rust
- Gray Leaf Spot
- Healthy

The project follows CRISP-DM and includes image auditing, cleaning, RGB conversion, resizing, stratified splitting, augmentation, CNN modeling, transfer learning, and evaluation.

Models are evaluated using accuracy, precision, recall, macro F1-score, and confusion matrices.
